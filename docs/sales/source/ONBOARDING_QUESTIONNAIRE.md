## 2. Что должен уметь ассистент

Отметьте `[x]` нужное. Каждый пункт включает соответствующий раздел в админке.

- [ ] **Записи** — ассистент записывает клиентов (на приём, визит, просмотр, тест-драйв и т.п.).
      → модуль `booking`, раздел «Записи».
- [ ] **Партнёры** — проверка сотрудников компаний-партнёров (напр. корпоративные клиенты по списку).
      → модуль `partners`, раздел «Партнёры».
- [ ] **Расписание** — ассистент сообщает график специалистов / врачей / мастеров.
      → модуль `schedule`, раздел «Расписание».
- [ ] **Ночные заявки** — ассистент принимает обращения вне рабочих часов в отдельную очередь.
      → модуль `night_queue`, раздел «Заявки».

Базовые разделы (звонки, обращения, объекты, аналитика, настройки) включены
всегда — отдельно отмечать не нужно.

### Для платформы (заполняет KomekAI)

По заполненной анкете:
1. Раздел 2 → модули организации (`/api/clinics`, поле `modules`) — выставляются
   при создании организации галочками в форме «Новая организация».
2. Разделы 3–5 → скин: можно собрать в «Настройках ассистента» вручную или
   импортом YAML (см. `ORG_ONBOARDING.md`).
3. Раздел 6 → `did_numbers` организации, CRM-коннектор.
