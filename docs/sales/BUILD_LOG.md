### Шаг 14 — Исправление найденных проблем
- Внесены правки в `worker/mm-bot.js` по всем 11 пунктам ревью:
  - **Критичное:** handoff менеджеру теперь содержит полный номер клиента (маска — только в логах); при сбое Claude бот не молчит — отправляет клиенту мягкий ответ + handoff менеджеру с причиной `bot_unavailable`; история диалога защищена от гонки (перечитка свежей копии + мерж перед записью).
  - **Существенное:** дедуп-маркер `seen` ставится после успешной доставки ответа; webhook secret принимается из query ИЛИ заголовка `X-Webhook-Secret`; `sendWazzupMessage` получил retry-loop (429/5xx) и возвращает bool; `BOT_KV` добавлен в проверку конфигурации.
  - **Минорное:** проверка пустого `chatId`; обработка `stop_reason: refusal`; история сохраняется только при успешной доставке; `appendTurn` больше не мутирует входной массив.
- Синтаксис: `node --check` — OK.
- **Результат:** код бота прошёл ревью и доработан, готов к деплою.

### Шаг 24 — MANAGER_CHAT_ID, баг парсера, боевой тест, отключение
- Прописан реальный `MANAGER_CHAT_ID = 77003131515`, Worker передеплоен.
- **Баг парсера webhook:** проверка `if (m.status) continue` отсекала ВСЕ входящие — у Wazzup каждое входящее имеет `status: "inbound"`. Исправлено на `if (m.status && m.status !== 'inbound')`. Формат webhook сверен по реальному payload (временный лог `RAW_WEBHOOK`).
- **Боевой тест выявил проблемы:**
  - Промпт ломается: на нестандартном сообщении (рабочий чат с партнёром-косметологом) бот вышел из роли — повёл себя как генеративный ассистент («помогу оформить ответ клиенту»).
  - Слоты ненастоящие: время записи бот генерирует в коде (`buildSlotsBlock`, фикс. 11/14/17), реальной занятости Altegio не знает.
  - Бот не здоровается на первом сообщении.
  - Подтвердилась проблема основного номера — бот отвечает во всех чатах, включая рабочие/партнёрские переписки.
- **Бот отключён** по запросу пользователя: подписка Wazzup `messagesAndStatuses` = false (проверено GET-запросом). Worker и секреты на месте — включается обратно одним PATCH.
- **Перед повторным запуском:** усилить промпт (не выходить из роли), решить по слотам (Altegio / убрать конкретное время), добавить приветствие, решить по номеру (рекомендация — отдельный номер под рекламу).
