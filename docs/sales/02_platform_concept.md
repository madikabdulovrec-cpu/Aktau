# Платформа аналитики отдела продаж — концепция

## Назначение

Сквозная атрибуция и анализ работы отдела продаж M&M Fabrica:
- UTM-метки → понимаем, какой канал даёт деньги
- WhatsApp-диалоги → видим работу каждого продавца
- Связка с Altegio → доводим лида до записи и оплаты
- Связка с [clients_platform](../../clients_platform/) → видим путь после оплаты курса (анамнез, сеансы, результаты)
- AI-разбор диалогов → выявляем «почему не закрыли»

## Три слоя

### Слой 1. Сбор данных

**UTM-метки → WhatsApp.**
- Каждый канал ведёт на свою ссылку `wa.me/77XXXXXXXXX?text=Здравствуйте%20%5Butm_source=instagram_reels%5D`
- Бот парсит метку из первого сообщения и привязывает к лиду
- Альтернатива надёжнее: разные номера WA для разных каналов

**Подключение к WhatsApp — три варианта:**

| Вариант | Плюсы | Минусы | Цена |
|---|---|---|---|
| **WhatsApp Cloud API (Meta)** | Официально, не банится | Верификация бизнеса 1-3 недели | $0.05-0.10/диалог |
| **Wazzup24 / Pact (агрегатор)** | Подключение за 1 день, WA + Instagram DM + Telegram в одном API, поддержка на русском | Привязка к третьей стороне | 25-40k ₸/мес |
| **Green-API / 1msg / Chat-API** | Дёшево | Неофициально, риск бана номера WhatsApp в любой момент | ~$10/мес |

**Рекомендуется Wazzup24** для быстрого старта.

### Слой 2. Хранение и связи

- Каждое сообщение → Firestore (как уже сделано для [clients_platform](../../clients_platform/))
- Каждый лид связывается с:
  - Источником (UTM)
  - Продавцом
  - Записью в Altegio (если дошёл до консультации)
  - Карточкой в clients_platform (если купил)
  - Оплатой (если оплатил курс)
- Это даёт сквозную атрибуцию: «Instagram Reels → лид → Айгерим закрыла → 280 000 ₸»

### Слой 3. Аналитика

**Базовая (без AI):**
- Дашборд по продавцам: число лидов, время первого ответа, конверсия в консультацию, конверсия в продажу, средний чек
- Воронка по каналам: какой источник даёт самые горячие лиды
- SLA-алерты: «лид не отвечен 15 минут», «лид без действия 24 часа»
- Лента диалогов с фильтрами

**AI-анализ (Claude API):**
- После закрытия диалога LLM разбирает по чек-листу:
  - Спросили имя?
  - Задали анамнез?
  - Предложили курс?
  - Назвали цену?
  - Предложили рассрочку?
  - Обработали возражения?
  - Пригласили на консультацию?
- Скоринг каждого диалога (0-10)
- Алерты руководителю: «Айгерим не предложила курс 3 диалога подряд»
- Стоимость: ~$0.01-0.03 за разбор одного диалога

## Развилка: строить или купить

### Вариант A. Готовое (Wazzup24 + amoCRM)
- 2-3 дня настройки, 50-80k ₸/мес
- **Получаете:** WhatsApp в одном окне, базовую воронку, отчёты, запись звонков
- **Не получаете:** AI-анализ по вашим критериям, интеграцию с clients_platform, привязку анамнеза к продаже, кастомные алерты

### Вариант B. Своё с нуля
- MVP 3-4 недели, полная версия 2-3 месяца
- **Получаете:** всё под ваш процесс, AI-разбор по вашему чек-листу, интеграция со всеми системами, полный контроль над данными
- **Стоимость:** время + 25-40k ₸/мес инфраструктура

### Вариант C — рекомендуемый. Гибрид
- Wazzup24 берёт на себя WhatsApp + Instagram (стабильно, легально, дёшево)
- Своя платформа поверх его webhook + Firestore + Altegio + clients_platform — аналитика и AI
- Запуск MVP за 2 недели
- Стоимость: ~30k ₸/мес Wazzup + ~5-10k ₸/мес AI токены + 0 на хостинг (Cloudflare free tier)

## Архитектура (Вариант C)

```
[Клиент пишет в WA с UTM]
        ↓
[Wazzup24] → webhook → [Cloudflare Worker]
                            ↓
                      [Firestore: leads, messages]
                            ↓
                    ┌───────┴───────┐
                    ↓               ↓
            [Dashboard]       [Claude API]
            (HTML SPA)        (анализ чата)
                    ↓
            [Altegio API]
            (запись на консультацию)
                    ↓
            [clients_platform]
            (если купил → анамнез + фото)
```

**Стек уже знаком:** Cloudflare Worker + Firestore + HTML SPA + Altegio API — то же, что в [clients_platform](../../clients_platform/) и [worker/altegio-webhook.js](../../worker/altegio-webhook.js).

## MVP (2 недели работы)

Минимум, который сразу даёт ценность:

1. Подключение Wazzup24, webhook → Firestore
2. Парсинг UTM из первого сообщения
3. Лента лидов с фильтрами (продавец, статус, источник)
4. Метрики: время первого ответа, конверсия в консультацию, конверсия в продажу
5. SLA-алерт в Telegram руководителю: «лид не отвечен 30 минут»
6. Связка лида с записью в Altegio (по номеру телефона) → видна вся цепочка до денег

Без AI-разбора. AI добавляется во второй итерации.

## Дорожная карта

| Неделя | Что готово |
|---|---|
| 1-2 | MVP платформы: webhook от Wazzup, Firestore, лента лидов, базовые метрики |
| 3 | Связка с [clients_platform](../../clients_platform/) по номеру телефона → полная карта пути |
| 4 | AI-разбор диалогов по чек-листу + классификация лидов по персонам |
| Месяц 2 | Sankey-визуализация CJM, алерты, динамика по неделям/месяцам |

## Юридическая сторона

- Анализ переписки клиентов = обработка персональных данных. По ЗРК «О персональных данных» нужно согласие. Стандартное решение: в первое автосообщение бота вшивается «Продолжая диалог, вы соглашаетесь с обработкой данных в соответствии с политикой [link]».
- Запись и анализ диалога продавца — нужно уведомить сотрудников. Закрепить в трудовом договоре.

## Что нужно для старта
