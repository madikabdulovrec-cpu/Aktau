омниканальным чатом (модуль `chat/` — WhatsApp/Telegram/Instagram),

**Бот M&M (`worker/mh-bot.js`) — тактическая standalone-реализация
на Cloudflare Worker (JS) для быстрого закрытия M&M через CRM
message.help, которой нет в KomekAi.** Долгосрочно — миграция M&M в скин
KomekAi (нужен будет message.help-адаптер в `chat/`-модуле). Решение от
2026-05-22: M&M-бот доводим до боевого запуска отдельно, миграция позже.
**Не путать репозитории:** `madikabdulovrec-cpu/M-M` (этот, M&M-кухонная
свалка: сайт + академия + бот) и `Evimiz-KZ/KomekAi` (платформа Komek).

## VERIFY — подтвердить на первом боевом тесте

В коде помечены `VERIFY`-комментарии:
- формат вебхука `channel.message.created` (есть лог `RAW_WEBHOOK`);
- `send_message` с `destination=from_operator` — доходит ли ответ клиенту;
- возвращает ли message.help наши исходящие сообщения вебхуком (эхо-защита);
- `get-user` — точное поле телефона клиента;
- `contact_by_phone` — поле `id` контакта;
- Altegio: `clients/search`, `book_dates`/`book_times` — поля `visit_count`, `booking_dates`/`working_dates`.

После успешного теста — убрать `RAW_WEBHOOK`-лог из `mh-bot.js` (он жирный, в проде не нужен).

## Полезные команды

Запускать из `worker/` директории на устройстве, где сделан `wrangler login`:

```bash
# Логи в реальном времени
npx wrangler tail --config wrangler-mh-bot.toml

# Передеплой после правок mh-bot.js или wrangler-mh-bot.toml
npx wrangler deploy --config wrangler-mh-bot.toml

# Обновить секрет
printf '%s' "NEW_VALUE" | npx wrangler secret put SECRET_NAME --config wrangler-mh-bot.toml

# Список секретов (только имена)
npx wrangler secret list --config wrangler-mh-bot.toml

# Healthcheck
curl https://mh-bot.madik-abdulov-rec.workers.dev/
```

## На другом устройстве — что делать новой сессии Claude

1. Установить Node.js 18+ и Git (если нет).
2. Склонировать репо: `git clone https://github.com/madikabdulovrec-cpu/M-M.git`
3. Скопировать `deploy-secrets.local.txt` с USB-флешки в `M-M/worker/`.
4. Авторизоваться в Cloudflare (один раз на устройство):
   ```bash
   cd M-M/worker
   npx wrangler login
   ```
   OAuth в браузере, аккаунт `Madik.abdulov.rec@gmail.com`. На Windows если PowerShell блокирует — `npx.cmd wrangler login` или обычный cmd.
5. Открыть Claude Code в папке `M-M` (или родительской), первым сообщением:
   ```
   Продолжаем проект бота M&M. Прочитай docs/sales/HANDOFF.md — там состояние и следующие шаги.
   ```

Этот HANDOFF + код в репо + секреты с USB = полный контекст. Всё нужное уже запушено в GitHub.
