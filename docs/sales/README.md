# Отдел продаж M&M Fabrica — рабочее пространство

Эта папка — точка входа в проект «усиление отдела продаж». Сюда складываются артефакты (анализ, концепции, ТЗ, скрипты, CJM).

## Контекст

В мае 2026 отдел продаж выполнил план на **17%**. Анализ показал, что главная просадка — **продажи абонементов (-70% к прошлому периоду)**, при том что услуги выросли (+17%). Это значит, клиенты приходят на разовые процедуры вместо курсов — отдел продаж разучился закрывать в курс на физической консультации.

## Открытые вопросы к пользователю

Чтобы двигаться дальше, нужны ответы:

1. Сколько продавцов в отделе?
2. Сколько консультаций в день в среднем (хотя бы по неделе)?
3. План отдела в **штуках абонементов** на месяц (а не в деньгах)
4. KPI продавцов сейчас — есть ли бонус именно за абонемент vs разовую услугу?
5. Какой канал WhatsApp использует отдел сейчас (личный WA / Wazzup / amoCRM / нет / другое)?
6. Старый CJM, если уже рисовался — нужна основа, не хочется делать с нуля
7. Подтверждение источников лидов (Instagram / 2GIS / сайт / WA напрямую / рекомендации) — для UTM-меток
